## Context

原住民立委（山地／平地）各自是**全國單一選區**，選民就是原住民本身，
所以那個選舉不需要生態推論就能讀。但它回答的是「投給哪個人」，
不是「傾向哪個政黨」——原住民立委多為無黨籍或地方勢力。

政黨票（不分區）是全體選民一起投的，沒有按族別分開計票。要從它讀出原住民的
政黨傾向，必須處理識別問題。本設計的核心決定是：**不做無法驗證的統計外推，
改為輸出「觀察值＋數學上必然的區間」**。

## Goals / Non-Goals

**Goals:**

- 不分區政黨票五屆進入建置，輸出投開票所層級的長表與逐屆席次表
- 逐投開票所算出原住民選民佔比 p 與投票者佔比 q，兩者都輸出
- 分三個門檻輸出**觀察值＋Duncan-Davis 極限法的上下界**
- 極限法的界限同時作為**建置時的守門員**：估計值落在界外即中止
- 官方數字與估計值分表、分欄名，下游不可能誤讀成同一個權威等級
- `elrepm` 的出生日期／出生地／學歷不進任何輸出

**Non-Goals:**

- 不做生態迴歸外推到佔比 = 1
- 不宣稱涵蓋全體原住民（都市平地原住民在門檻外）
- 不處理總統票、區域立委票、公投
- 不改動地方公職與原住民立委既有的六張長表
- 不處理 2016 的 `old/` 目錄（已具名排除）

## Decisions

### 決策 1：輸出「觀察值＋極限」而不是單一估計值

Duncan-Davis 極限法只依賴算術：該層觀察到的得票率 y、投票者中原住民佔比 q，
則原住民支持率必然落在 `[max(0,(y-(1-q))/q), min(1, y/q)]`。

實測 2024 的 ≥95% 層（90 所、32,635 張有效政黨票、q = 0.9705）：

| 政黨 | 觀察 | 原住民必落在 | 寬 |
| --- | ---: | --- | ---: |
| 中國國民黨 | 68.10% | [67.13%, 70.17%] | 3.0pp |
| 台灣民眾黨 | 14.09% | [11.47%, 14.51%] | 3.0pp |
| 民主進步黨 | 12.09% | [9.42%, 12.46%] | 3.0pp |

替代方案是生態迴歸取佔比 = 1 的外推值。不採用：八成以上的所原住民佔比
低於 20%，斜率會被非原住民與都市原住民定錨，而 `p = 1` 落在樣本支援之外。
更關鍵的是**兩者的失效方式不對稱**——極限法錯不了（它是算術），
迴歸外推錯的時候數字看起來精確而且沒有任何跡象。

⚠️ 外部覆核（codex）指出一句必須寫進文件的話：「取 p=1 的外推值」不等於
估計出原住民票，它是「在指定模型下的預測」，不該被描述成觀察值。

### 決策 2：權重用 q（投票者佔比）不用 p（選舉人佔比）

分解式 `y = q·y_I + (1-q)·y_N` 裡的權重是**投票者**佔比，不是選舉人佔比。
兩者不等，差距來自兩張票的投票率不同。

實測 ≥95% 層兩者只差 0.4–1.6 個百分點（2024：原住民票投票率 68.7%、
全體 68.4%），但**差距小不是「可以混用」的理由**——用錯的那個會讓界限算錯，
而算錯的界限仍然看起來像界限。兩者都輸出，讓讀者能自己看差距。

⚠️ 這一條是外部覆核抓到的，我原本的框架把 p 當成 q。

### 決策 2b：「不在原住民檔內」有兩種意思，用反向缺口區分

`p = 0` 與 `p = 未知` 不是同一件事，而「該所不在原住民檔內」兩種都可能：

- **(a) 該所沒有原住民選民** → `p = 0` 是量出來的事實
- **(b) 兩個檔的所號對不上** → `p` 是未知

判準是**該縣市的反向缺口**：若每一個原住民所都在政黨票檔內（反向缺口 = 0），
那麼政黨票檔多出來的所必然沒有原住民選民；兩向都有缺口時，
代表所號對不上，不能斷言 `p = 0`。

實測結果：**2020 嘉義市屬 (a)**（反向缺口 0，且那兩個特設所的 p 恰為 1.0000），
**2024 的七個縣市屬 (b)**。因此 2020 的可用率是 **100%** 而不是 98.90%——
第一版把它算成缺口，是把已知的零當成未知。

⚠️ 這個判準由資料算出而非宣告，安全性來自 `EXPECTED_JOIN`：
缺口數一改變就中止，不會靜默地在 (a) 與 (b) 之間切換分類。

⚠️ 輸出另立 `缺席原因` 欄（`該所無原住民選民`／`所號兩檔對不上`／
`該所選舉人或投票數為 0`），讓下游能區分三種情形而不是只看到空白。

### 決策 3：三個門檻都輸出，不挑一個

| 門檻 | 涵蓋原住民選舉人 | 國民黨區間寬 |
| --- | ---: | ---: |
| ≥95% | 11.0% | 3.0pp |
| ≥90% | 20.7% | 4.8pp |
| ≥80% | 28.4% | 7.5pp |

涵蓋率與精度是直接的取捨，挑一個等於替讀者做決定。
⚠️ 實測**點估計幾乎不隨門檻移動**（國民黨 68.10／67.50／67.18），
這是穩定性的證據——但它只證明高佔比層之間一致，**不證明能推廣到都市**。

外部覆核（agy）主張 ≥80% 的極限區間「非常窄」。實測**不成立**：7.5pp，
是 ≥95% 的 2.5 倍。設計據實測值而非該主張。

### 決策 4：估計值與官方數字分表分欄

官方數字（政黨得票、席次）進 `cec-party-list-*`；
估計值進**另一個檔** `indigenous-party-preference-bounds.csv`，
欄名一律帶 `觀察_`／`下界_`／`上界_` 前綴，並含 `門檻`、`所數`、
`涵蓋原住民選舉人`、`涵蓋率`、`q`、`p` 等範圍欄位。

下游不可能只讀到一個看起來像官方值的欄位。

### 決策 5：極限法本身就是守門員

估計值無法寫「斷言估計等於真值」，但可以斷言 `下界 ≤ 觀察 ≤ 上界`
與 `0 ≤ 下界 ≤ 上界 ≤ 1`。這是數學上無懈可擊、且**真的會失敗**的檢查——
若權重或公式寫錯，界限會與觀察值矛盾。

### 決策 6：選區欄逐檔宣告允許值，並在配對時忽略

普查已確認四個檔對這一欄的用法各不相同，且 2008 與 2012 起不同。
沿用專案既有的作法：宣告每個檔的允許值集合，出現宣告外的值即中止；
配對時忽略該欄。不忽略的話 2008 有 22,555 個單位對不上。

## Implementation Contract

**Behavior**：新增四份輸出。

既有的六張長表（地方公職三張、原住民立委三張）**逐位元不變**。

**Interface / data shape**：

- 極限法：`下界 = max(0, (y - (1 - q)) / q)`、`上界 = min(1, y / q)`，
  其中 `y` = 該層該黨得票 / 該層有效政黨票，
  `q` = 該層原住民投票數 / 該層總投票數
- 門檻集合宣告為常數 `(0.95, 0.90, 0.80)`，以選舉人佔比 `p` 篩所
- `elrepm` 只讀不輸出；若未來要輸出，欄位白名單必須排除 idx 4／6／7

**Failure modes**（全部中止）：

- `elretks` 的當選人數合計 ≠ 34（五屆皆 34）
- `elretks` 的第一階段或第二階段得票率合計 ≠ 100.00%
- 某個政黨代號在同一屆對到兩個不同名稱
- 極限法的界限不滿足 `0 ≤ 下界 ≤ 觀察 ≤ 上界 ≤ 1`
- 某門檻的所數或涵蓋率與宣告值不符
- 輸出欄位含 `elrepm` 的出生日期／出生地／學歷

## Risks / Trade-offs

**風險 1：界限只約束「非原住民混入」，不約束「地理選擇偏誤」。**
極限法給的區間在數學上必然成立，但它回答的是「這 90 所裡的原住民」。
都市平地原住民（31.8%）在門檻外，**極限法對他們給不出有用的界限**
（佔比 <5% 時區間寬到 0–100%）。文件必須把這件事寫在最前面，
而不是當成註腳——否則一個數學上無懈可擊的區間會被讀成全體原住民的區間。

**風險 2：可用的門檻樣本很小。** ≥95% 只有 90 所、32,635 張有效政黨票。
單一政黨的小數字（時代力量 1.36%）界限下界會被壓到 0，區間資訊量低。
處置：輸出時保留原始票數，讓讀者能自己判斷哪個政黨的數字站得住。

**風險 3：2024 有 125 所對不上，原因未查明。** 已量出位置（123 個在
<20% 的鄉鎮市區），對高佔比層影響最多 2 所。但**原因未明**這件事本身要
寫進報告的具名清單，並在對不上的比例超過宣告值時中止——
不可因為「這次影響小」就不記。

**取捨：三個門檻 vs 一個。** 三個增加了輸出的複雜度，也讓讀者可能挑對自己
有利的那個。但挑一個等於替讀者隱藏取捨，而涵蓋率 11% 與 28% 的差別
足以改變結論的可信範圍。
