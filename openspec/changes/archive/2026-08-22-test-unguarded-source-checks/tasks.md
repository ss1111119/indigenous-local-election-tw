## 1. 探測骨架

- [x] 1.1 在 `scripts/test_build_local_election.py` 建立這一組的共用骨架：一個取得真實 parts 的快取函式（找不到原始壓縮檔時記入 `skipped` 並回傳 `None`），以及一個 `aborts_with(label, mutate, phrase)` 工具——它深拷貝 parts、套用 `mutate`、呼叫 `cross_validate`，並斷言**中止且錯誤訊息含 `phrase`**。落實設計決策「合成方式：取真實 parts 深拷貝後改一格」與「測試放在既有檔案，不另立新檔」，實現 Requirement: A Compensating Check Is Not Considered Tested Until An Input Exists That Trips It。⚠️ 只斷言「有拋出例外」不算滿足契約，`phrase` 必須是**只有目標檢查會輸出的字串**。驗證方式：先斷言未改動的 parts 餵進 `cross_validate` **不中止**（基準；少了它，後續的「中止」可能來自 parts 本身有問題）；再以已實測可行的第 30 項作為骨架的自我驗證，斷言它中止且訊息含該單位的鍵。

## 2. cross_validate 上的八項

- [x] 2.1 補第 30 項（投票數 > 選舉人數的具名檢查）與第 33 項（具名單位的上層級補償）。30 的輸入：取 1998 T3 一個**不在** `KNOWN_ELECTOR_ANOMALIES` 內的鄉鎮市區列，把 `投票數` 設為 `選舉人數 + 1`。33 的輸入：取具名的寶山鄉那一筆，把它的**上層級**（選舉區／縣市／檔別合計三者之一）也設成投票數超過選舉人數。驗證方式：兩者皆中止；30 的訊息含該未具名單位的鍵、33 的訊息含「其上層級」字樣以區別於 30。
- [x] 2.2 補第 31 項（配錯選舉區的多重集合）與第 34 項（鄉鎮市區代碼集合差異）。31 的輸入：在具名的錯置選舉區內，把某一個鄉鎮市區列的有效票改成另一個值，使 elprof 與 elctks 的多重集合不再相同。34 的輸入：在同一個選舉區內刪掉一個鄉鎮市區列，使代碼集合出現不在 `moved_towns` 具名清單內的差異。驗證方式：兩者皆中止且訊息可區別——31 屬多重集合、34 屬代碼集合，兩條檢查相鄰且都與鄉鎮市區有關，必須確認觸發的是各自那一條。
- [x] 2.3 補第 41 項（孤兒層級向上加總）、第 42 項（孤兒單位的父單位不存在）與第 45 項（孤兒層級須嚴格深於 elprof）。41 的輸入：把某個孤兒單位的得票改掉，使其向上加總不等於父層級有效票。42 的輸入：從 `summary` 移除該孤兒單位的父層級列。45 的輸入：讓某個孤兒單位的層級不比 elprof 最深層級更深。⚠️ 實測探測時「移除全部直轄市縣市列」**沒有觸發** 42——輸入必須精確對到那個孤兒單位的父鍵。驗證方式：三者皆中止且訊息各自可區別。
- [x] 2.4 補第 43 項（驗證 7 的鍵不套用選舉區正規化）。⚠️ 它使唯一性檢查**恆為真**而非移除檢查，所以「中止／不中止」測不到，落實設計決策「第 43 項要斷言「正規化真的有發生」」，實現 Requirement 的場景 A check is made vacuous rather than removed。驗證方式：取四個 `DISTRICT_COLUMN_INCONSISTENT` 直轄市檔之一，斷言**套用正規化後的鍵集合大小 < 未套用時的大小**——正規化把選舉區欄壓成 `00`，若不做，鍵會因該欄不同而多出若干個。斷言的是一個會因變異而改變的數，不是例外。

## 3. 另外兩個入口

- [x] 3.1 補第 44 項（忽略選舉區欄後候選人身分仍唯一）。它在 `derive_elected_authoritative` 內且只在 `ignore_district=True` 時執行，故直接呼叫該函式。輸入：兩位候選人在（省市, 縣市, 鄉鎮市區, 村里, 號次）五欄完全相同、只有選舉區欄不同。⚠️ 實測第一版合成輸入**被更早的「候選人複合鍵重複」檢查攔截**——落實設計決策「三個入口，不是一個」中所述的處置：斷言訊息含只有身分唯一檢查會輸出的措辭；若仍被攔截，調整輸入使其只違反目標檢查。驗證方式：中止且訊息可與「複合鍵重複」區別。
- [x] 3.2 補第 40 項（選舉區欄的允許值）。它在 `process_one` 內、讀檔後組裝前。落實設計決策「三個入口，不是一個」。依 design 的 Open Questions，實作時二選一：直接呼叫 `process_one` 於既有最小檔別（1998 T-COMBO，10 名候選人），或抽出該檢查片段單獨呼叫；兩者皆須滿足契約，以執行時間較短者為準並在註解說明選了哪一個。輸入：讓某個來源檔的選舉區欄出現宣告集合以外的第三種值。驗證方式：中止且訊息含該檔名與實際取值。
