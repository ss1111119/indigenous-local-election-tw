About this translation

This page is translated by the project and has not been reviewed by a native speaker. The Chinese version governs. Election-type names are rendered by this project and are not official translations; where a name has no established English form it is kept in Chinese. The Chinese original is at index.html. The roster page has no English version: it lists 4,607 candidate names, and this project has no authoritative romanisation for them.

Scope

What is covered, and what is not

This is not a complete list of indigenous local elections. T1 (regional councilors) is a reference group, not indigenous data; R2 covers only the plain indigenous representative seats in those townships, not all of their seats.

Terms and gaps

2009-2010 is one term of office voted on two dates — before the 2014 consolidation, county councilors (2009-12-05) and special municipality councilors (2010-11-27) did not vote on the same day. Treating them as one term is this project's modelling judgement, not a division the source supplies.

That term has only T2, T3 and T1: D2 and R3 did not yet exist; R2 is excluded because the 2010 township representative file is a single national file from which plain indigenous seats cannot be separated. An election type absent in a term is marked as absent, never filled with 0 — the line is left blank and the table says "no such election" or an em dash.

⚠ That term's administrative codes are an entirely different encoding, not interchangeable with 2014 onward (2009 Yilan County 03,002, 2010 Taipei City 01,000; from 2014 they are 10,002 and 63,000). Cross-term comparison by administrative unit must exclude it.

Not covered: township mayors and township representatives (regional seats) in indigenous areas, village chiefs, and county magistrates or city mayors.

⚠ There is no 1994 county councilor data — the archive contains only Taiwan Provincial Assembly members and special municipality councilors. Whether that election was held is not something this project verified; only that it is not in the zip. So 1994 shows 6 indigenous seats and 1998 shows 55, and the two must not be drawn as one line — it would read as an explosion of representation in 1998.

⚠ 1994 provincial assembly members and the combined special-municipality "indigenous" category are excluded from every cross-term chart and shown separately in the last section. The provincial assembly was abolished in 1998; the combined category does not split plain from mountain, so its granularity differs from T2/T3.

01

Turnout

The county councilor series (T2/T3) runs continuously from 1998, seven points in all; D2, R3 and R2 were created only in 2014 and have three. The description below covers 2009-2010 onward only — the earlier terms were added in this round and have not yet been compared segment by segment.

T2 and T3 rose from 2009-2010 through 2018 (+3.08/+1.00 and +4.98/+0.56 percentage points), and only 2018→2022 fell across the board, by 4.51 to 7.33 points in all six types. The reference group T1 fell in all three segments, but the first two by only 0.86 and 0.69; the last by 5.83.

What this data does not support

"Turnout is in continuous decline" — across the four points from 2009-2010 onward, T2 and T3 rose until 2022; the fall is concentrated in the final term.
"Indigenous willingness to vote is falling" — the reference group T1 fell 5.83 points over the same period.
Any causal claim.

This project got this wrong twice. With only 2018 and 2022 it wrote "declining"; adding 2014 changed it to "flat then declining"; only after adding 2009-2010 did it become clear that T2 and T3 had been rising. Each additional point rewrote the previous reading.

02

Parties

The chart shows the party composition of seats won, each segment labelled with its seat count. "Independent" is party code 999 in the source, officially "independent / not party-nominated", which includes anyone without a party nomination. The 1994–2005 files use code 99 and the name "none"; this page merges them into the same category, which is why the older terms show independent seats at all.

Limits

These are seat counts, not votes. Party vote share would have to be computed from the votes long table, which this page does not do.

The DPP appears in T3 across three terms as 10 candidate records, none elected, and has no candidate records in R3. The source files carry no cross-term candidate identifier, so this page always says "candidate records" rather than "people".

03

Gender

Each cell is one seat won; filled cells are women.

D2, indigenous district chiefs

18 seats won across three terms; women won 0. Women's candidate records over the same period were 1 in 2014, 2 in 2018 and 0 in 2022 — women did stand, and none were elected in any of the three terms.

D2 has only 6 seats per term, so one seat is 16.7 percentage points. This is a complete count of those 6 seats, not a sample estimate, but it cannot support any claim about causes or general patterns.

Elected under the women's quota (source mark !)

Easily miscounted

Counting only * misses these seats, and nothing reports an error. This project keeps the source mark in its own field; both * and ! count as elected. Seats on this site always come from the authoritative elected field — a judgement reconciled across the candidate, vote and profile files — not from the source mark, which is corrupt in two 2005 files and under-counts 19 seats. The source also uses - for a candidate displaced by the women's quota. ⚠ This project previously claimed - never appears in the three recent terms — in fact there are 12 in 2014 and 8 in 2018, all men, all correctly counted as not elected.

04

Scale, incumbents and uncontested seats

Limits

D2 and R3 are held in the same indigenous districts on the same day and their electorates overlap heavily, but their official elector counts are not identical (2022: 31,807 and 31,803). Different election types must not be added together; doing so double-counts severely.

T1 covers every regional councilor district, from the six metropolitan areas to rural counties. It is here only as a national baseline; treating it as an otherwise-comparable control is wrong.

D2 and R3 had no incumbents standing in 2014 — the indigenous districts were created by the 2014 amendment to the Local Government Act, and that was the first election.

Appendix

National electors divided by seats, as a rough ratio

This is not a representation metric

This project has not defined a representation metric at the local level. What follows is only a reproducible descriptive ratio.

It divides a national total, so it hides local variation; and ratios from different election types should not be compared as representation or fairness — R3 and T1 measure different institutional units, differing in level of office, geographic scope and powers.

Separate

Two office types kept out of the cross-term lines

None of the charts above include this section's data. These are election-type codes coined by this project (the official code table covers only 2022, and neither office exists in it); the codes contain a hyphen to mark them as such.

Taiwan Provincial Assembly members (T-PRV2 / T-PRV3) — the provincial assembly was abolished when the province was streamlined in 1998. It is a different office from today's county councilors and must not be added to them. The 1994 "plain" and "plain 2" files are two constituencies, not a duplicate (the candidates are entirely different). That file's base record has a single row for "Taiwan Province"; the source gives no constituency name.

The combined special-municipality "indigenous" councilor category (T-COMBO) — 2 seats in each of 1994, 1998, 2002 and 2006 (one each in Taipei and Kaohsiung). Plain and mountain are not split: the source base file has no constituency level and the candidate file's constituency column is 00 throughout, so no field can separate them. T2 and T3 are mutually exclusive, and this category is their union — so it is neither.

Why this is not drawn as a line

1994 has 6 indigenous seats (4 provincial plus 2 combined municipality); 1998 has 55. Joining them into one line would read as an explosion of representation in 1998 — when in fact the archive simply has no 1994 county councilor data. Whether that election was held is not something this project verified; only that it is not in the zip.
