# 立委頁六色配色的量測紀錄

產生方式（兩條指令的輸出原樣貼上，未經編輯）：

```
python scripts/palette_metrics.py "#2a78d6,#1baf7a,#ee7700,#c0397a,#3A4046,#ADB3B9" \
  --labels 中國國民黨,民主進步黨,親民黨,無黨團結聯盟,無黨籍,其他 --all-pairs \
  --inks "#000/#2a78d6,#16181A/#1baf7a,#16181A/#ee7700,#fff/#c0397a,#fff/#3A4046,#16181A/#ADB3B9"
```

## 為什麼六色而不是沿用地方選舉頁的四色

地方選舉頁只有三個政黨桶加「其他」。立委頁必須有五個政黨桶：親民黨在 2001 年
拿 27.7%、無黨團結聯盟在 2004 年拿 26.0%，套三桶會讓那兩屆的主要故事掉進「其他」。

相鄰配對數因此從 3 增為 10（全配對 15）。**既有配色不保證還夠用**，所以上面兩組
都是重新量的，且量的是全配對不是相鄰配對——圖例在窄螢幕折行後，原本不相鄰的
兩個系列會直接上下相接。

## 變異對照

量測本身要能失敗，否則上面那兩個「全部通過」不帶任何資訊。實測：

| 變異 | 結果 |
| --- | --- |
| 親民黨 `#ee7700` → `#22b884`（與民進黨綠相近） | 未過門檻 2 組，exit 1 |
| 無黨團結聯盟的段內墨色 `#fff` → `#16181A` | 對比 3.48 < 4.5，exit 1 |
| 未變異的基準 | 全部通過，exit 0 |

⚠️ 用管線接 `tail` 會讓 exit code 變成 `tail` 的，上面三個 rc 都是不接管線量的。
