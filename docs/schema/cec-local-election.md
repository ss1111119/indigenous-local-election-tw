```python
import pandas as pd

s = pd.read_csv("data/processed/cec-local-election-summary-long.csv.gz", dtype=str)

# 全國投票率——city 與 prv 是互斥的行政區劃分，必須相加
t = s[s["層級"] == "檔別合計"].astype({"投票數": int, "選舉人數": int})
```

## ⚠️ 讀之前必須知道的五件事

### 一、`層級` 欄決定一切，沒有它就別加總

原始檔把**彙總列與明細列混在同一個檔案裡**。直接對得票或票數加總，
數字會暴增數倍——因為每一票被算了好幾次（投開票所一次、村里一次、
鄉鎮市區一次、選舉區一次、縣市一次）。

`層級` 欄是本專案依官方格式文件的補零規則算出來的，值有六種：

| 層級 | 意義 |
| --- | --- |
| `檔別合計` | 該檔案範圍的總計（**不是全國**，見第二點） |
| `直轄市縣市` | 縣、省轄市或直轄市 |
| `選舉區` | 該縣市內的選舉區 |
| `鄉鎮市區` | |
| `村里` | |
| `投開票所` | 最細一層 |

**要加總請先篩層級。** 例如全部得票只能取 `層級 == "投開票所"`，
或改取某一個較粗層級，兩者不可混用。

### 二、`檔別合計` 不是全國——`city` 與 `prv` 要相加

T2 分成兩份檔案，兩者是**互斥的行政區劃分**：

- `city`：宜蘭、新竹、苗栗、彰化、南投、屏東、臺東、花蓮 8 縣＋基隆、新竹 2 市
- `prv`：臺北、高雄、新北、臺中、臺南、桃園 6 直轄市

兩份的 `檔別合計` 各自只是**該檔範圍內的小計**，相加才是全國：

| 檔別 | 選舉人數 | 投票數 | 投票率 | 候選人 | 當選 |
| --- | ---: | ---: | ---: | ---: | ---: |
| city | 112,461 | 66,835 | 59.43% | 46 | 23 |
| prv | 90,016 | 39,738 | 44.15% | 27 | 11 |
| **全國** | **202,477** | **106,573** | **52.63%** | **73** | **34** |

⚠️ **全國投票率是本專案的計算值**（合計投票數／合計選舉人數），
原始檔中不存在這個數字。各檔別自己的投票率則直接取自原始檔並已交叉驗證。

建置腳本會檢查兩份檔案的縣市代碼不重疊，重疊即中止。

### 三、當選人不是只有 `*`

原始檔的當選註記有**四個值**（官方格式文件明定），本表保留原值於
`當選註記`，並提供已解讀的 `當選註記語意` 與布林式的 `當選`：

| 原值 | `當選註記語意` | `當選` |
| --- | --- | --- |
| `*` | 當選 | Y |
| （空白） | 未當選 | N |
| `!` | **婦女保障當選** | **Y** |
| `-` | 因婦女保障被排擠未當選 | N |

**只數 `*` 會系統性少算當選人，而且不會報錯。** 2022 年 T2 未出現
`!`，但同年 R2 少 2 席、T1/city 少 3 席、T1/prv 少 1 席。
請一律用 `當選 == "Y"`，不要自己判斷註記。

### 四、行政區代碼一律是字串，不要轉成數字

`省市`／`縣市`／`選舉區`／`鄉鎮市區`／`村里`／`投開票所` 六欄都是字串：

- **補零形式本身帶語意**：`000` 代表「該層級以上的彙總」，轉成數字就沒了
- **村里代碼首碼可能是英文**：官方格式文件說明，跨多個村里的投開票所
  由中選會另行自訂代碼（如 `A001`）。T2 目前 0 列，但解析器仍須支援

讀取時請用 `dtype=str`。

### 五、候選人資料已做個資最小化

原始 `elcand.csv` 含**出生日期、出生地、學歷**。中選會〈網站資料開放宣言〉
明訂：個人資料能否蒐集處理利用，使用者須自行依個人資料保護法辦理——
開放授權不免除這一條。

因此本表**不輸出**這三欄。保留的是：

- `姓名`——公職候選人姓名屬選舉公開資訊，且是識別候選人的必要欄位
- `性別`、`年齡`、`現任`、`政黨`——分析參選結構所需，識別性遠低於出生日期

要這三欄請自行回原始壓縮檔取用，並自行承擔個資法上的責任。

### `cec-local-election-summary-long.csv.gz`（23,198 列）

選舉概況，來自 `elprof.csv`。每個行政層級一列。

| 欄 | 說明 |
| --- | --- |
| `層級`、`投開票所` | 見第一點 |
| `有效票`、`無效票`、`投票數` | **`有效票 + 無效票 = 投票數`**，建置時逐列驗證 |
| `選舉人數`、`人口數` | `人口數` 的底層來源未查證，見 README「尚未解決」 |
| `候選人數`、`當選人數` | 由版面偵測結果取出，見下 |
| `投票率` | 原始檔的值（`投票數 / 選舉人數`） |
| `版面` | 偵測到的 `elprof` idx11–16 欄位順序，保留作為可稽核性的一部分 |

⚠️ **`有效票` 與 `無效票` 曾被本專案誤記為「投票數 男／女」。**
那個錯誤不會被「男＋女＝合計」的自我驗證攔下（`63,768 + 3,067 = 66,835` 一樣成立）。
語意以官方格式文件為準，經過為何見 README。

**版面偵測**：官方格式文件（民國 101 年）記 idx11–16 為
「候選合計, 當選合計, 候選男, 候選女, 當選男, 當選女」，但 2022 年實際資料是
「候選男, 候選女, 候選合計, 當選男, 當選女, 當選合計」。兩種各自算術自洽，
只能靠「男＋女＝合計」分辨。**兩種皆不通過即中止，絕不套用預設版面**——
套錯會得到看起來合理但完全錯誤的席次且不報錯。

### `cec-local-election-candidates-long.csv`（73 列）

| 欄 | 說明 |

### `cec-local-election-votes-long.csv.gz`（91,755 列）

候選人得票，來自 `elctks.csv`。每位候選人在其選舉區內的各行政層級各一列。

| 欄 | 說明 |
| --- | --- |
| `層級`、`投開票所` | 見第一點——**這張表最容易被誤加總** |
| `號次` | 對應 candidates 表的 `號次`（需同時比對行政區與檔別） |
| `得票數`、`得票率` | |
| `當選註記` | |

⚠️ **這張表沒有 `檔別合計` 與 `直轄市縣市` 層級**，最粗的層級是 `選舉區`。
因為候選人只在一個選舉區參選，跨選舉區的得票加總沒有意義。
選舉區層級的列數（73）恰等於候選人數。

要各縣市或全國的**票數**請用 summary 表的 `有效票`／`投票數`；
votes 表只回答「某位候選人在某個地方拿到多少票」。

實測層級分布：`選舉區` 73、`鄉鎮市區` 1,058、`村里` 26,081、`投開票所` 64,543。

## 建置時執行的自我驗證

任何一項不通過即中止。輸出先全部算完、驗完，才**一次性替換**——
中途失敗不會留下新舊混雜的半套結果。

**結構層**

1. 每個檔的欄數**逐列**必須恰好符合官方格式文件（`elbase` 6／`elcand` 16／
   `elpaty` 2／`elprof` 20／`elctks` 10）。只驗「至少幾欄」會讓多出的欄位靜默通過
2. 用 `csv.reader` 而非 `split(",")`。官方文件要求資料內容不得含逗號，
   但那是對提供端的要求，不是對讀取端的保證
3. `elprof` 的行政單位鍵（6 碼）不得重複——重複列會讓後續所有加總驗證失去意義
4. 候選人複合鍵（行政區 ＋ 號次）不得重複

**數值層**

5. `有效票 + 無效票 = 投票數`（逐列）
6. 票數欄不得為負；`投票數` 不得大於 `選舉人數`
7. `投票數 / 選舉人數` 重算後 ＝ 原始檔的投票率（容差 0.01）

**跨檔對帳**

8. `elprof` idx11–16 通過「男＋女＝合計」。兩種版面皆不通過即中止；
   **兩種同時通過也中止**（例如全為 0 時），不可靜默採用第一種
9. `elcand` 的實際列數 ＝ `elprof` 的候選人數
10. `elcand` 中 `當選 == "Y"` 的列數 ＝ `elprof` 的當選人數
11. **逐一行政單位**：該單位所有候選人的得票加總 ＝ `elprof` 同單位的有效票。
    2022 年 T2 共比對 23,180 個單位。⚠️ 早期版本只比對**總和**，
    那會放過互相抵銷的錯誤（A 少 10 票、B 多 10 票，總和照樣通過）
12. 參照完整性：`elctks` 出現的每個行政單位都必須存在於 `elprof`
13. `elcand` 與 `elctks` 的當選註記必須一致
14. 當選註記只能是官方定義的四個值，出現未知值即中止
15. `city` 與 `prv` 的縣市代碼不得重疊

驗證結果寫入 `data/processed/validation-report.json`，含來源檔 SHA-256。

### 測試與已知的驗證缺口

`python scripts/test_build_local_election.py`（也可用 pytest）跑 49 項：
單元測試涵蓋層級判定、版面偵測、CSV 讀取、當選註記、gzip 可重現性；
迴歸測試把 2022 T2 的實際數字釘死（列數、層級分布、各檔別與全國數字）。

已用**變異測試**確認測試套件真的會失敗，並因此發現一個缺口：

⚠️ **2022 年 T2 完全沒有 `!`（婦女保障）列**，所以把 `!` 從當選判定中拿掉，
建置與所有**迴歸**測試都會照樣通過。這條邏輯目前只由**單元測試**守住。
真正會踩到的是 R2（少 2 席）與 T1（少 4 席），但那些還不在建置範圍內。
擴充到那些選舉種類時，迴歸測試才會真正覆蓋這條。
